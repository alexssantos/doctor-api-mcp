doctor-api-mcp foi instalado no namespace {{ .Release.Namespace }}.

1. Aguarde o rollout:
   kubectl rollout status deployment/{{ include "doctor-api-mcp.fullname" . }} -n {{ .Release.Namespace }} --timeout=180s

2. Abra um túnel local:
   kubectl port-forward service/{{ include "doctor-api-mcp.fullname" . }} 4000:{{ .Values.service.port }} -n {{ .Release.Namespace }}

3. Acesse:
   Dashboard: http://localhost:4000/dashboard
   MCP:       http://localhost:4000/
   Health:    http://localhost:4000/health
