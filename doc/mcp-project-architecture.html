Architecture · doctor-api-mcp

MCP observability platform

How MCP clients and operators enter the platform, how the React dashboard and .NET backend share one delivery path, and how the server correlates application, database, Kubernetes, and telemetry signals.

Implemented today

The dashboard is built into and served by McpServer. Two backend replicas correlate Kubernetes, Prometheus, Jaeger, Loki, and OpenAPI data. ProdutoAPI and PrecoAPI each own an independent PostgreSQL database.

Planned boundary

Redis is shown as the intended shared cache and persistence layer. The current observability cache is process-local, so entries are isolated per McpServer replica.
